[MiRo-E, hardware and software]

Hardware: for the hardware we can utilize the Miro’s built-in hardware, such as the actuated
eyes and 3 DoF neck. This should give us enough creative freedom to express physical
expressions effectively.

A MiRo extension kit which  can be used to have miro do more things or give it
tools
- Add a outer thing to back to add extra speakers for questions but keep lights visible
- Add sensors for heartrate/other physiological stuff to make the reactions more specific
(need to touch the robot)
- Make the robot dance/dance mode to lift mood
- Add a timer for the breathing exercise
- Add wings
Software: We can use the built-in speaker to enable Miro to talk with the students. We do not
need too much of an emphasis on software, since the verbal and physical communication can
be puppeteered by a human.
Outer design: We can create accessories or other components for the Miro (e.g. different ears,
collars, clothes, or other add-ons) to make the robot fit into the decided scenario. In the case of
university students.
What can be wizard-of-ozzed:
- The talking and possibly limited physical expressions
- In principle everything could be wizard-of-ozzed

Experiment:
- Theatre exercise to see how students respond to checkin
- Theatre exercise for different types of check-in
- Theatre exercise with different kinds of questions/ themes
- Theatre exercise to see how students answer certain prompts.
- Theatre exercise to see how students facial expression change.
