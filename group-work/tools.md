# Design Tools

## Selected Tools
We selected tools from the User Innovation Toolkit:

- Scenario Analysis
- Storyboard
- Experience Map

Reference: https://userinnovationtoolkit.ugent.be/#/toolkit

---

## Scenario Analysis
Used to imagine future interactions between students and the MiRo robot.

- Helps understand user behavior
- Allows role-playing scenarios
- Identifies problems before implementation

---

## Storyboard
Visual representation of interaction.

- Shows robot-user interaction step-by-step
- Captures emotions and expressions
- Useful for design communication

---

## Experience Map
Tracks user experience over time.

- Compare: with vs without robot
- Helps evaluate impact
- Useful during design and testing
